# 시험기간 화이팅!

시험 공부와 시험기간 일정을 한 곳에서 관리하는 웹사이트입니다.
설치할 것도, 서버를 켤 것도 없습니다. **`index.html` 을 더블클릭**하면 바로 열립니다.

---

## 화면 구성

| 화면 | 하는 일 |
|---|---|
| **홈** | 앞으로 7일 주간 달력, 시험 D-day, 오늘 처리할 일, 학습 현황, 약한 단원 |
| **일정 · D-day** | 월간 달력 + 시험 · 과제 · 대외활동 · 기타 일정 관리 |
| **공부 계획 · 진도** | 과목별 진도율, 과목별 공부 계획(할 일), 단원 체크리스트, 과목 · 단원 추가 |
| **문제 풀기** | 조건을 골라 출제 + 지난 세션 기록 다시 풀기 |
| **약점 보완 퀴즈** | 오답률 높은 단원 + 아직 못 넘긴 오답 문제를 섞어 출제 |
| **오답노트** | 틀린 문제 모아 보기, 메모, 다시 풀기 |

| **자료로 문제 만들기** | PDF · 필기를 문제로 바꿔 한 번에 수십 개 넣기 |
| **문제 추가 · 편집** | 브라우저에서 한 문제씩 만들기, 코드로 내보내기 |
| **백업 · 초기화** | 기록 내보내기 / 가져오기 / 지우기 |

## 달력

**홈 — 앞으로 7일**
오늘부터 7일을 가로 띠로 보여 줍니다. 종류별 색이 붙어서 시험인지 과제인지 바로 구분됩니다.
날짜를 누르면 일정 화면으로 넘어갑니다.

**일정 · D-day — 월간 달력**
일정 추가 폼 위에 있습니다. 제목만 큼직하게 띄우고, 한 칸에 3개까지 보이며 넘치면 `+n` 으로 표시합니다.

- **빈 칸을 누르면** 그 날짜로 아래 폼의 날짜가 채워집니다.
- **일정을 누르면** 바로 수정 모드로 들어갑니다.
- `‹` `›` 로 달을 옮기고, `오늘` 로 이번 달로 돌아옵니다.
- 위쪽 종류 필터를 바꾸면 달력도 같이 걸러집니다.

### 며칠에 걸친 일정

과제나 대외활동처럼 하루에 끝나지 않는 일은 **시작일과 마감일**을 따로 넣을 수 있습니다.
마감일을 비워 두면 하루짜리 일정이 됩니다.

기간 일정은 달력에서 시작일부터 마감일까지 **띠처럼 이어져** 보이고 (이어지는 날은 제목이 흐리게),
목록에는 `9월 9일 (수) ~ 9월 15일 (화) 18:00 마감 (7일)` 처럼 표시됩니다.

D-day 는 상황에 따라 다르게 나옵니다.

| 상태 | 표시 |
|---|---|
| 아직 시작 전 | `시작 D-3` |
| 시작했고 진행 중 | `진행 중` + `마감 D-4` |
| 마감일 당일 | `오늘 마감` |
| 마감 지남 | `3일 지남` |

시각을 넣으면 마감일의 마감 시각으로 해석합니다.

## 공부 계획 · 진도

한 과목 안에서 두 가지를 따로 관리합니다.

**1. 공부 계획** — 문제 풀이가 아닌 할 일을 적는 곳입니다.
"교재 3장 정독", "필기 PDF 정리", "기출 2개년" 처럼 자유롭게 쓰면 됩니다.
입력하고 Enter 만 누르면 추가되고, 체크하면 아래로 내려갑니다.

**2. 단원 진도** — 단원 체크리스트입니다. 펼치면 단원별 정답률과 문제 수도 같이 보입니다.
단원 옆의 작은 `풀기` 는 "다 봤다"고 체크하기 전에 바로 확인해 보라고 둔 버튼입니다.
목록 맨 아래 `＋ 단원 추가` 로 단원을 언제든 더 넣을 수 있습니다.

### 단원마다 PDF · 필기 걸어 두기

단원을 펼치고 `＋ 자료` 를 누르면 그 단원의 교재 PDF, 필기 스캔, 강의 링크를 걸어 둘 수 있습니다.
개수 제한은 없고, 누르면 새 탭에서 열립니다.

**파일 자체는 저장되지 않습니다.** 브라우저 저장소는 5MB 남짓이라 PDF 가 들어가지 않습니다.
대신 *어디에 있는 파일인지* 경로만 기억합니다. 그래서 세 가지 방식이 가능합니다.

| 적는 방법 | 예시 | 비고 |
|---|---|---|
| **자료 폴더에 넣고 상대 경로** (권장) | `자료/항해학_1장.pdf` | 폴더째 옮겨도 링크가 살아 있음 |
| 컴퓨터 안 다른 위치 | `C:\Users\...\항해학.pdf` | `file:///` 로 자동 변환 |
| 웹 주소 | `https://drive.google.com/...` | 구글 드라이브, 노션 등 |

> 두 번째 방식(`C:\...`)은 **`index.html` 을 더블클릭해서 열었을 때만** 열립니다.
> 로컬 서버로 띄우면 브라우저가 내 컴퓨터 파일 접근을 막습니다.
> 첫 번째 방식이 어디서든 안전합니다.

파일 탐색기에서 파일을 `Shift + 우클릭` → **경로로 복사** 하면 전체 경로가 복사됩니다.
따옴표가 같이 붙어도 알아서 떼어냅니다. 이름을 비워 두면 파일명이 그대로 제목이 됩니다.

자세한 건 `자료/README.md` 에 적어 뒀습니다.

각 과목 카드 **맨 위**에 그 과목의 진도율이 큰 숫자와 **칸 나눈 막대**로 함께 나옵니다.

```
▪▪▪ ▪▪▪ ▪▪▪ ▫▫▫ ▫▫▫ ▫▫▫   50%   ← 단원 6개 중 3개 완료
```

**한 무리가 단원 하나**입니다 (무리 사이가 조금 더 벌어져 있습니다). 다 본 단원은 칠해지고, 전부 채우면 초록색으로 바뀝니다.
단원이 많으면 다음 줄로 넘어갑니다.
칸에 마우스를 올리면 어느 단원인지 나오고, **칸을 눌러도 바로 체크**됩니다
(아래 단원 목록을 펼치지 않아도 됩니다).

시험 일정을 등록해 둔 과목에는 D-day 배지도 같이 붙습니다.
모든 과목을 합친 전체 진도율은 화면 맨 위에 따로 있습니다.

### 과목 · 단원 추가하고 지우기

같은 화면 맨 아래 **과목 · 단원 관리** 에서 합니다. 파일을 고칠 필요 없습니다.

- `＋ 과목 추가` — 과목 이름과 단원을 쉼표로 구분해 입력
- 과목 줄의 `＋ 단원` — 기존 과목에 단원 덧붙이기 (단원 목록 아래에도 같은 버튼이 있습니다)
- `과목 지우기` / 단원의 `지우기` — 필요 없어진 과목 · 단원을 목록에서 뺍니다

여기서 추가하면 문제 필터, 문제 편집기의 드롭다운, 통계까지 전부 자동으로 따라옵니다.

**지울 때 무슨 일이 일어나나**

| 대상 | 결과 |
|---|---|
| 내가 추가한 과목 · 단원 | 정말로 지워집니다 |
| `data/curriculum.js` 의 기본 과목 · 단원 | 화면에서만 빠집니다 (파일은 그대로) |

기본 항목을 지우면 화면 아래 **목록에서 뺀 항목** 칸에 모여서, `다시 표시` 로 언제든 되돌릴 수 있습니다.

지울 때 그 과목에 딸린 기록(푼 기록 · 오답 · 공부 계획 · 진도 · 자료 링크 · 내가 만든 문제)이
몇 개인지 알려 주고, **기록도 같이 지울지 따로 한 번 더 묻습니다.**
기록을 남겨 두면 과목을 되살렸을 때 그대로 돌아옵니다.

> `data/questions.js` 에 들어 있는 문제는 브라우저에서 지울 수 없습니다.
> 그 문제까지 없애려면 파일에서 직접 지워야 합니다.

## 문제 풀기 기록

세션을 끝내면 **문제 풀기** 화면 아래 `지난 문제 풀기 기록` 에 남습니다.
날짜, 문항 수, 정답률과 함께 그때 나온 문항 id 까지 저장되므로

- **같은 구성으로** — 그때 그 문제를 순서까지 그대로
- **순서 섞어** — 같은 문제를 순서만 바꿔서

다시 풀 수 있습니다. `문항` 을 누르면 어떤 문제였는지 목록으로 펼쳐 볼 수 있습니다.
약점 보완 퀴즈나 오답노트에서 푼 세션도 함께 기록됩니다.

> 문제를 나중에 삭제하면 그 문항은 다시 풀기에서 빠지고, 기록에 "n문제는 삭제됨" 으로 표시됩니다.

| 유형 | 채점 방식 |
|---|---|
| 4지선다 | 자동 채점. **보기 순서는 매번 섞여서** 나옵니다 |

| 단답 주관식 | 자동 채점. 공백과 문장부호는 무시하고 비교, 허용 표기도 인정 |
| 서술형 | **자동 채점 불가.** 모범답안과 채점 키워드 목록이 나오고, 본인이 맞음/틀림을 선택 |

난이도는 하 · 중 · 상 3단계이며 유형과 따로 고를 수 있습니다.

## 약점 보완 퀴즈가 동작하는 방식

1. 푼 기록에서 **단원별 오답률**을 계산합니다 (3회 이상 푼 단원만 대상).
2. 오답률 높은 순으로 단원 순위를 매기고, 상위 5개를 자동 선택합니다.
3. 두 갈래를 섞어서 출제합니다.
   - **틀렸던 문제 그 자체** — 많이 틀린 것부터
   - **약점 단원의 다른 문제** — 같은 개념을 다른 각도에서

비중은 화면에서 30 / 50 / 70 / 100% 중에 고를 수 있습니다.
같은 문제만 반복하면 내용이 아니라 답을 외워 버리기 때문에 기본값은 50%입니다.

오답은 **연속 2회 맞히면** 자동으로 "극복"으로 넘어가고 출제 대상에서 빠집니다.

## 문제를 늘리는 방법

### 1. PDF · 필기 → 문제 (가장 빠름)

**자료로 문제 만들기** 화면이 이걸 위한 화면입니다.

> 먼저 알아 둘 것: 이 사이트는 PDF 를 **스스로 읽어 문제를 만들지 못합니다.**
> 그건 AI 호출이 필요해서 API 키와 요금이 듭니다.
> 대신 AI 와의 왕복을 세 번의 클릭으로 줄여 놨습니다.

1. **[요청문 복사]** — 지금 등록된 과목·단원 목록과 문제 형식이 통째로 들어간
   지시문이 복사됩니다. 몇 문제 만들지, 어느 과목으로 할지도 고를 수 있습니다.
2. Claude 같은 AI 대화창에 **PDF나 필기 사진과 함께** 붙여넣습니다.
3. 돌아온 JSON 을 **[붙여넣기]** 칸에 넣고 **[미리보기] → [추가]**.

AI 가 앞뒤에 설명을 붙이거나 ` ```json ` 으로 감싸도 알아서 걸러냅니다.
형식이 어긋난 문제는 **이유와 함께 건너뛰고**, 나머지만 들어갑니다.
목록에 없는 과목·단원이 나오면 **[이 과목 · 단원 만들기]** 버튼 한 번으로 만들 수 있습니다.

#### 요청문이 AI 에게 시키는 것

요청문에는 **지어내지 말라는 지시**가 들어 있습니다.

- 첨부한 자료에 적힌 것만으로 만들 것. AI 가 따로 아는 지식을 보태지 말 것
- 근거를 못 찾으면 **"자료에 없음"** 이라고 적을 것
- 자료가 짧아 개수를 못 채우면 **억지로 채우지 말고** 만들 수 있는 만큼만 줄 것
- 모든 문제에 **정답 · 해설 · 출처**를 넣을 것
- 최소 **10문제** (한 번에 너무 적게 받으면 왔다 갔다 하는 품이 더 듭니다)

#### 들여올 때 걸러지는 것

| 상황 | 앱이 하는 일 |
|---|---|
| 해설이 없음 | 그 문제만 건너뜀 (이유를 보여 줌) |
| 출처가 없거나 "자료에 없음" | 들어가되 **출처 없음** 표시 + 몇 개인지 알려 줌 |
| 10개보다 적음 | 경고만 하고 막지는 않음 |

10개보다 적어도 **추가는 됩니다.** 자료에 없는 내용을 억지로 채우는 것보다
적게 만드는 편이 낫기 때문입니다.

### 2. 간단 서식으로 직접 타이핑

같은 화면의 **간단 서식** 탭입니다. JSON 을 손으로 치기 싫을 때 씁니다.

```
4지선다 | 항해학 | 항해 계기 | 중
진북을 지시하는 계기는?
*자이로컴퍼스
마그네틱컴퍼스
선속계
음향측심기
> 자이로컴퍼스는 진북을, 마그네틱컴퍼스는 자북을 지시한다.

OX | 해사법규 | 항법 | 하
추월하는 선박이 피항한다.
정답: O
```

첫 줄이 `유형 | 과목 | 단원 | 난이도`, 빈 줄로 문제를 구분합니다.
4지선다는 정답 보기 앞에 `*`, 해설은 `>` 로 시작, 나머지는 `정답:` 줄에 답을 씁니다.
`허용:` (단답의 다른 표기) 과 `키워드:` (서술형 채점표) 도 쓸 수 있습니다.

### 3. 한 문제씩 꼼꼼히 — 문제 추가 · 편집

폼으로 하나씩 만듭니다. 이미 만든 문제를 고칠 때도 여기입니다.

### 4. `data/questions.js` 직접 편집

1·2·3 번으로 만든 문제는 **브라우저에 저장**됩니다.
영구 보관하려면 **문제 추가 · 편집** 화면 아래 **[코드로 내보내기]** 로 복사해
`data/questions.js` 에 붙여 넣으세요. 형식은 아래 참고.

## 파일 구조

```
app/
├─ index.html              ← 이걸 더블클릭 (또는 웹에서 /app/)
├─ css/style.css           ← 색·폰트는 파일 맨 위 변수만 고치면 전체가 바뀜
├─ data/
│  ├─ curriculum.js        ← 과목과 단원의 기본 목록 (화면에서 추가한 건 브라우저에 저장)
│  └─ questions.js         ← 문제 은행  ★ 여기를 제일 자주 고치게 됩니다
└─ js/
   ├─ store.js             ← 브라우저 저장소, 과목·단원 병합
   ├─ app.js               ← 라우터, 통계 계산
   ├─ calendar.js          ← 월간 · 주간 달력
   └─ views/               ← 화면 10개
```

저장소 루트에는 소개 페이지(`index.html`), 앱 정보(`manifest.webmanifest`),
오프라인 지원(`sw.js`), 아이콘(`icons/`)이 있습니다.

`자료/` 폴더에는 교재 PDF·필기를 넣습니다. 자세한 건 `자료/README.md` 참고.

`fetch()` 대신 `<script src>` 로 데이터를 불러오기 때문에
로컬 서버 없이 `file://` 로 열어도 동작합니다.

## 문제 형식

`data/questions.js` 에 아래 형태로 넣습니다.

```js
// 4지선다 — answer 는 정답 보기의 인덱스 (0부터)
{
  id: "nav-011",
  subject: "항해학",          // curriculum.js 의 과목 이름과 정확히 일치
  unit: "항해 계기",          // curriculum.js 의 단원 이름과 정확히 일치
  source: "항해학_기초.md · 3. 항해 계기",   // 어느 자료 어디에서 나왔는지
  type: "mcq",
  difficulty: 2,             // 1=하, 2=중, 3=상
  prompt: "문제 내용",
  choices: ["보기1", "보기2", "보기3", "보기4"],
  answer: 0,
  explain: "해설"
}

// OX
{ ..., type: "ox", answer: true,  explain: "...", source: "..." }

// 플래시카드 — prompt 가 앞면, answer 가 뒷면
{ ..., type: "flash", answer: "뒷면 내용\n줄바꿈도 그대로 보임",
  explain: "...", source: "..." }

// 단답 — altAnswers 에 적은 표기도 정답 처리
{ ..., type: "short", answer: "편류", altAnswers: ["drift"],
  explain: "...", source: "..." }

// 서술형 — keywords 가 자가 채점표로 나옴
{ ..., type: "essay",
  answer: "모범답안",
  keywords: ["핵심어1", "핵심어2"],
  explain: "...", source: "..." }
```

### 정답 · 해설 · 출처는 모든 문제에 있어야 합니다

| 항목 | 없으면 |
|---|---|
| `answer` | 채점이 안 됩니다 |
| `explain` | 화면에 **자료에 없음** 이라고 뜹니다. 편집 화면과 일괄 등록에서는 아예 거부됩니다 |
| `source` | 화면에 **출처: 자료에 없음** 이 노란색으로 뜹니다 |

`source` 는 해설 맨 끝에 `출처: …` 한 줄로 붙습니다. 서식은 **파일이름 · 항목**.

```
항해학_기초.md · 2. 방위와 침로
필기노트.pdf · 12쪽
```

### 해설도 자료 안의 말로만

**정답과 출처만 자료에서 가져오고 해설은 알고 있는 것으로 채우면, 규칙을 반만 지킨 것입니다.**
해설도 자료에 적힌 범위 안에서 써야 합니다.

```js
// 자료: "윤활유 계통: 마찰 저감과 냉각, 밀봉, 세정 역할을 함께 수행한다."

// 이렇게 쓰면 안 됩니다 — 각 역할의 설명은 자료에 없습니다
explain: "마찰 저감은 기름막을 만드는 것, 냉각은 마찰열을 실어 나르는 것, ..."

// 이렇게 쓰세요 — 자료에 있는 것만
explain: "윤활유 계통 하나가 마찰 저감·냉각·밀봉·세정 네 가지를 함께 맡는다."
```

들어 있는 샘플 30문제가 이 기준으로 쓰여 있으니 참고하세요.

### 자료에 없으면 "자료에 없음"

문제를 만들다 보면 **자료에서 근거를 못 찾는** 경우가 생깁니다.
이때 그럴듯하게 지어내면 틀린 것을 외우게 됩니다. 그러지 말고 그대로 적으세요.

```js
source: "자료에 없음"
```

그러면 앱이 그 문제를 노란색으로 표시해서, **자료로 확인된 것이 아니라는 것**을
푸는 사람이 바로 알 수 있습니다. 모르는 것을 모른다고 두는 편이 낫습니다.

### 주의할 점

- **`id` 는 절대 중복되면 안 됩니다.** 중복되면 오답노트와 통계가 엉킵니다.
- 4지선다 해설에 **"1번은 ~"처럼 번호를 쓰지 마세요.**
  보기 순서가 매번 섞이기 때문에 화면과 어긋납니다. 보기 내용을 그대로 쓰세요.

### `subject` / `unit` 이름에 대해

**문제 추가 · 편집 화면에서는 신경 쓸 필요 없습니다.** 드롭다운에서 고르기 때문에 항상 일치합니다.

주의가 필요한 건 `data/questions.js` 를 **손으로 직접 편집할 때**뿐입니다.
과목 · 단원 이름이 목록에 없는 것으로 적히면, 그 문제는 출제는 되지만
**단원별 정답률과 약점 분석에서 빠집니다.**

이름이 어긋난 문제가 있으면 **공부 계획 · 진도** 화면 맨 아래에 경고가 뜹니다.
그때는 둘 중 하나를 하면 됩니다.

1. 그 화면에서 해당 이름의 단원을 추가한다
2. `questions.js` 쪽 이름을 목록에 맞게 고친다

## 기록은 어디에 저장되나요

**이 브라우저 안에만** 저장됩니다 (localStorage). 서버로 나가지 않습니다.

그래서 이런 점을 알아 두세요.

- 다른 기기나 다른 브라우저에서는 기록이 보이지 않습니다.
- 브라우저 방문 기록 · 사이트 데이터를 지우면 **함께 사라집니다.**
- 시크릿 모드에서는 창을 닫는 순간 사라집니다.

시험 전에 **백업 · 초기화** 화면에서 한 번 내보내 두면 안전합니다.
같은 화면에서 다른 기기로 가져오기도 됩니다.

저장되는 항목: 푼 기록 · 오답노트와 메모 · 일정 · 진도 체크 · 공부 계획 ·
직접 추가한 과목과 단원 · 직접 추가한 문제 · 문제 풀기 기록 · 테마
