# 자료 폴더

교재 PDF, 필기 스캔, 정리 노트 같은 파일을 **이 폴더에 넣으세요.**

그런 다음 사이트의 **공부 계획 · 진도** 화면에서 단원을 펼치고
`＋ 자료` 를 눌러 이렇게 적으면 됩니다.

```
자료/항해학_1장.pdf
```

이렇게 상대 경로로 적어 두면, 폴더째 USB 로 옮기거나 다른 컴퓨터에 복사해도
링크가 그대로 살아 있습니다.

---

## 파일 이름 짓기

한글도 되고 띄어쓰기도 되지만, **띄어쓰기 대신 밑줄**을 쓰면 경로를 적을 때 덜 헷갈립니다.

```
항해학_1장_항법의종류.pdf
선박기관_2장_디젤기관.pdf
해사법규_필기_0911.jpg
```

과목별로 하위 폴더를 만들어도 됩니다.

```
자료/항해학/1장.pdf   →  자료/항해학/1장.pdf 로 적으면 됩니다
```

---

## 이 폴더에 넣지 않고 링크만 걸고 싶다면

**컴퓨터 안 다른 위치의 파일**
파일 탐색기에서 파일을 `Shift + 우클릭` → **경로로 복사** 한 다음 그대로 붙여 넣으세요.
`C:\Users\...\항해학.pdf` 같은 경로가 자동으로 링크로 바뀝니다.

> 단, 이 방식은 `index.html` 을 **더블클릭해서 열었을 때만** 열립니다.
> 로컬 서버(http://localhost)로 띄우면 브라우저가 내 컴퓨터 파일 접근을 막습니다.
> 이 폴더에 넣고 상대 경로로 적는 쪽이 더 안전합니다.

**구글 드라이브 · 노션 · 웹 강의**
주소를 그대로 붙여 넣으면 됩니다. `https://` 로 시작하면 새 탭에서 열립니다.

---

## 주의

사이트는 **경로만 기억합니다.** 파일 자체를 저장하지 않습니다.
파일을 옮기거나 이름을 바꾸면 링크가 깨지니, 그때는 링크를 지우고 다시 걸어 주세요.
