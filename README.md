# 시험기간 화이팅!

시험 공부와 시험기간 일정을 한 곳에서 관리하는 웹앱입니다.
회원가입도 설치도 필요 없고, 브라우저만 있으면 됩니다.

**웹에서 바로 쓰기 → <https://gijioo0604-hash.github.io/Exam-Period-Preparation-page/>**

폰이나 태블릿에서 열어 **홈 화면에 추가**하면 앱처럼 전체 화면으로 열리고,
인터넷이 끊겨도 동작합니다.

| 화면 | 하는 일 |
|---|---|

| **일정 · D-day** | 월간 달력 + 시험 · 과제 · 대외활동 관리 (시작일 ~ 마감일 기간 일정 지원) |
| **공부 계획 · 진도** | 과목별 할 일, 칸 나눈 진도 막대, 단원별 PDF 링크, 과목 · 단원 추가 |
| **문제 풀기** | 과목 · 단원 · 유형 · 난이도를 골라 출제 + 지난 세션 그대로 다시 풀기 |
| **약점 보완 퀴즈** | 단원별 오답률을 계산해 약한 곳만 집중 출제 |
| **오답노트** | 틀린 문제 자동 수집, 메모, 연속 2회 정답 시 극복 처리 |
| **학습 통계** | 일별 풀이량, 과목 · 유형 · 난이도 · 단원별 정답률 |
| **자료로 문제 만들기** | AI 요청문 생성 + JSON · 간단 서식으로 문제 일괄 등록 |
| **문제 추가 · 편집** | 한 문제씩 만들기, 코드로 내보내기 |
| **계정 · 동기화** | 로그인해서 폰·노트북 기록 맞추기 (선택) |
| **백업 · 초기화** | 기록 JSON 내보내기 / 가져오기 |

문제 유형은 **4지선다 · OX · 플래시카드 · 단답 · 서술형** 5가지,
난이도는 **하 · 중 · 상** 3단계입니다.

서술형만 자동 채점이 안 됩니다. 모범답안과 채점 키워드를 펼쳐 두고 본인이 맞음/틀림을 고릅니다.

## 폴더 구조

```
├─ index.html               ← 소개 페이지 (사이트 첫 화면)
├─ manifest.webmanifest     ← 홈 화면 추가용 앱 정보
├─ sw.js                    ← 서비스 워커 (오프라인 지원)
├─ icons/                   ← 앱 아이콘
└─ app/                     ← 앱 본체
   ├─ index.html
   ├─ css/style.css         ← 색은 파일 맨 위 변수만 고치면 전체가 바뀜
   ├─ data/
   │  ├─ curriculum.js      ← 과목 · 단원 기본 목록
   │  └─ questions.js       ← 문제 은행  ★ 여기를 제일 자주 고치게 됩니다
   ├─ js/
   │  ├─ store.js           ← 브라우저 저장소
   │  ├─ app.js             ← 라우터 · 통계 계산
   │  ├─ calendar.js        ← 월간 · 주간 달력
   │  ├─ gcal.js            ← 구글 캘린더 내보내기 · 연동
   │  ├─ sync.js            ← 로그인 · 기기 간 동기화 (Firebase)
   │  └─ views/             ← 화면 11개
   └─ 자료/                 ← 교재 PDF · 필기를 넣는 곳
```

빌드 도구가 없습니다. 파일을 고치고 새로고침하면 끝입니다.
`fetch()` 대신 `<script src>` 로 데이터를 불러오기 때문에
`app/index.html` 을 더블클릭해서 `file://` 로 열어도 그대로 동작합니다.

자세한 사용법은 [app/README.md](app/README.md) 를 보세요.

## 고치고 다시 올리기

```bash
git add -A
git commit -m "무엇을 바꿨는지"
git push
```

푸시하면 1~2분 안에 웹에 반영됩니다.

### 고친 게 안 보일 때 — 버전 두 곳을 올리세요

브라우저는 한 번 받은 `js/store.js` 를 한동안 다시 받지 않습니다.
그래서 **파일을 고쳐 올릴 때는 버전 숫자를 같이 올려야** 합니다.

1. `app/index.html` 의 `?v=10` → `?v=11` (전체 바꾸기로 한 번에)
2. `sw.js` 의 `var CACHE = "examhub-v10"` → `"examhub-v11"`

둘 다 올리면 폰에서도 다음 접속에 새 파일을 받습니다.
`data/questions.js` 만 고쳤을 때도 마찬가지입니다.

> 급하면 폰에서 새로고침을 두어 번 하거나, 브라우저 설정에서 이 사이트 데이터를 지우면 됩니다.
> 다만 사이트 데이터를 지우면 **학습 기록도 함께 사라지니** 먼저 백업하세요.

## 구글 캘린더 연동

**안 해도 됩니다.** 이 앱만으로 일정 관리는 다 되고, 처음 한 번만 물어본 뒤
안 쓰겠다고 하면 다시 묻지 않습니다. 나중에 [일정 · D-day] 화면에서 켤 수 있습니다.

켜면 세 가지 방법이 생깁니다. 위로 갈수록 설정이 필요 없습니다.

| 방법 | 설정 | 쓰임새 |
|---|---|---|
| **일정 하나씩** | 없음 | 일정 옆 `캘린더` 버튼 → 구글 캘린더 새 일정 화면이 채워진 채로 열림 |
| **파일로 한 번에** | 없음 | `.ics` 파일을 받아 구글 캘린더 → 설정 → 가져오기 |
| **바로 넣기** | 클라이언트 ID | 버튼 한 번으로 캘린더에 들어감 |

세 번째만 준비가 필요합니다. [구글 클라우드 콘솔](https://console.cloud.google.com/apis/credentials)에서
**OAuth 클라이언트 ID(웹 애플리케이션)** 를 만들고, 승인된 자바스크립트 원본에
**이 사이트 주소**를 넣은 뒤 발급된 ID 를 앱에 붙여넣으면 됩니다.
넣어야 할 주소는 앱 화면에 그대로 띄워 줍니다 (직접 포크해서 쓰는 경우에도 본인 주소가 나옵니다).

클라이언트 ID 는 사람마다 자기 것을 만들어야 합니다. 브라우저에만 저장되므로
같은 사이트를 쓰더라도 남의 것이 섞이지 않습니다.

> 구글 계정 정보는 앱이 보관하지 않습니다. 클라이언트 ID 만 이 브라우저에 저장되고,
> 로그인 토큰은 창을 닫으면 사라집니다. 일정을 **보내기만** 하고 읽어오지는 않습니다.

## 로그인 · 기기 간 동기화

**안 해도 됩니다.** 로그인 없이도 앱은 전부 동작합니다.
로그인은 **폰과 노트북에서 같은 기록을 보는 것** 하나만 더해 줍니다.

쓰려면 Firebase 프로젝트를 하나 만들어야 합니다. **[계정 · 동기화]** 화면이 네 단계로 안내합니다.

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트 만들기
2. 웹 앱 추가 → `firebaseConfig` 를 통째로 복사해 앱에 붙여넣기
3. Authentication → Google 로그인 켜기 + 승인된 도메인에 사이트 주소 추가
4. Firestore 만들고 **보안 규칙** 넣기 (화면에서 복사 버튼 제공)

무료 등급으로 충분합니다. 하루 읽기 5만 · 쓰기 2만인데 이 앱은 하루 수십 번 씁니다.
카드 등록도 필요 없습니다.

### 동기화가 동작하는 방식

기록은 **언제나 이 브라우저가 먼저**입니다. 인터넷이 끊겨도 그대로 쓰고,
바뀐 것이 있으면 잠시 뒤 클라우드로 올립니다. 앱을 열면 받아 와서 **합칩니다.**

합칠 때는 **지우는 것보다 남기는 쪽**을 택합니다.

| 자료 | 합치는 방법 |
|---|---|
| 푼 기록 · 세션 | 양쪽을 모으고 같은 것은 하나로 |
| 일정 · 계획 · 문제 · 자료 | 양쪽을 모으고, 같은 항목은 나중 것 |
| 오답 | 틀린 횟수는 큰 쪽, 메모는 최근 쪽 |
| 진도 · 숨긴 항목 | 어느 기기에서든 했으면 한 것으로 |

> 그래서 **한 기기에서 지운 것이 다른 기기에서 되살아날 수 있습니다.**
> 정리하고 싶을 때는 [계정 · 동기화] 의 `이 기기 것으로 덮어쓰기` 를 쓰세요.

Firebase 접속 설정은 기기마다 따로 저장되고 클라우드에 올리지 않습니다.

## 기록은 어디에 저장되나

기본은 **브라우저 안에만** 저장됩니다 (localStorage). 계정도 필요 없습니다.
위의 동기화를 켜면 Firebase 에도 같이 올라갑니다.

로그인하지 않았을 때는 이런 점을 알아 두세요.

- **기기마다 기록이 따로입니다.** 노트북에서 푼 기록이 폰에는 보이지 않습니다.
- 브라우저 사이트 데이터를 지우면 **함께 사라집니다.**
- 시크릿 모드에서는 창을 닫는 순간 사라집니다.

옮기거나 백업하려면 앱의 **백업 · 초기화** 화면에서 파일로 내보낸 뒤 다른 기기에서 가져오세요.

저장 항목: 푼 기록 · 오답노트와 메모 · 일정 · 진도 · 공부 계획 · 단원 자료 링크 ·
직접 추가한 과목/단원/문제 · 목록에서 뺀 과목/단원 · 문제 풀기 기록 ·
구글 캘린더 설정 · 테마

**백업 · 초기화** 화면에서는 항목별로 따로 지울 수도 있습니다.

## 들어 있는 문제

항해학 · 선박기관 · 해사법규 **샘플 30문제**가 들어 있습니다.
5개 유형과 3단계 난이도가 모두 한 번씩은 나오도록 넣어서, 각 화면이 어떻게 도는지 바로 볼 수 있습니다.

실제 시험 범위에 맞는 문제는 **자료로 문제 만들기** 화면에서 채우세요.
교재 PDF를 AI에 넘길 요청문을 만들어 주고, 돌아온 결과를 붙여넣으면 한 번에 수십 개가 들어갑니다.

> 샘플 문제는 교육 실습용 요약본을 바탕으로 만든 것입니다.
> 법령 원문이나 실제 시험 문제가 아니므로 정확한 내용은 원문과 교재로 확인하세요.
